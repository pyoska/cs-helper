# ECC AdSense Policy & Authenticity Shield Skill

This skill enforces 100% compliance with Google AdSense Policies and Quality Rater E-E-A-T Guidelines across `cshelper.kr`.

## 🛡️ Core Rules & Shields (AgentShield)

1. **Zero Deceptive Claims**:
   - NEVER generate fake real-time claims such as `"실시간 통화 대조 완료"`, `"대표 전담 평가원"`, `"실시간 전화 혼잡도"`, or simulated user voting counters.

2. **Mandatory Legal Disclaimer**:
   - EVERY page MUST render the legal disclaimer badge:
     `"⚠️ 본 정보는 참고용이며 공식 채널을 통해 재확인하십시오."`

3. **Official Affiliate / Non-Affiliation Disclaimer**:
   - Prominently display non-affiliation notices so users never mistake `cshelper.kr` for an official corporate site:
     `"본 사이트는 각 기업의 공식 고객센터가 아닌 정보 안내용 민간 포털입니다."`

4. **AdSense Layout Safety**:
   - NEVER place ads or sticky UI bars over critical text or `tel:` call buttons.
